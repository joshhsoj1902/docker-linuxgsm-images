Hi Everyone!

Press "y" to open chat.

Type "!setup" (or "!menu") for the setup menu:
  campaign, game mode, difficulty, character,
  or Gib Fest + Expert with a campaign picker.

The menu also opens automatically a few seconds after you join.

Other chat commands if you need them:
  "!maps"  campaign / map
  "!votemode"  game mode / mutation
  "!csm"  change character
