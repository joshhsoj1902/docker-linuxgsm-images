# L4D2 Setup Menu

Auto-opens a SourceMod menu after a human joins. Players can reopen it with `!setup` or `!menu`.

Items launch MapChanger (`sm_maps`), Vote Mode (`sm_votemode`), a difficulty vote, character select (`sm_csm`), and a Gib Fest + Expert quick start with a stock campaign picker.

Source: `../scripting/l4d2_setup_menu.sp`
